关于本预览的技术说明（请如实告知，不做过度承诺）：
1. 本页所有图标以 stroke（描边）路径 生成，端点/连接点均为圆角，符合线宽与视觉规范。
2. 需求文档要求交付前"必须将描边转换为闭合填充路径（Outline Stroke / Expand Stroke）"——这一步浏览器端无法可靠自动完成， 建议将下载的 .svg 导入 Illustrator / Figma，执行一次「路径 → 轮廓化描边」+「联集」后再交付，避免 Android 端渲染差异。
3. 已按需求做布尔合并的图标（如 ic_folder / ic_tag 等纯闭合形状）无需该步骤，可直接使用。
4. 五套主题图标（Markdown / Spark）保持同一符号，仅通过外框形状区分主题气质：Mono(直角方形) → Sunset(切角方形) → Forest(圆角方形) → Lavender(大圆角方形) → Ocean(圆形)，实际主题色由 App 运行时 tint 决定，源文件统一为黑色。
