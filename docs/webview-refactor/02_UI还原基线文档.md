## 3. 设计令牌（Design Tokens）

### 3.1 CSS 变量命名规范

主题切换采用双维度属性：`<html data-mode="light|dark" data-color="forest|ocean|sunset|lavender|mono|midnight">`

```css
[data-color="forest"] {
  --primary: #4B635A;      /* 品牌主色 */
  --primary2: #717E68;     /* 辅助主色 */
  --primary-soft: #E7EDDE; /* 主色柔和背景 */
  --primary-line: #C8D3C3; /* 主色边框 */
  --icon-html: #B4533C;    /* 类型图标色 */
  --icon-js: #8F752C;
  --icon-md: #3B6B78;
  --icon-prompt: #4B635A;
}
[data-mode="light"] {
  --bg: ...; --surface: ...; --surface2: ...;
  --text: ...; --text2: ...; --text3: ...;
  --line: ...; --code-bg: ...; --code-text: ...;
}
```

## 4. 图标资源

- 源：`res/drawable/ic_*.xml`（VectorDrawable，pathData 可机械转换为 SVG path）
- 已有 SVG 参考：`docs/svg/`（ic_grid / ic_list / ic_tree / ic_treetolist 等）
- 转换规则：`android:pathData` → SVG `d`；`android:fillColor` → `fill`（统一改为 `currentColor`，颜色由 CSS 控制）
- Markdown 类型图标有主题变体：`ic_md_forest/ocean/sunset/lavender/mono`，Web 端按 data-color 选择

## 6. 交互细节要求

| 项 | 要求 |
|---|---|
| 页面切换 | 保持原导航层级：BottomBar 三 Tab 平级，其余页面推入式返回 |
| 返回键 | Web 端逐层消费（关 Sheet/Dialog → 退页面 → 退出应用），通过 `app.backHandled` 与原生协作 |
| 长按 | 卡片长按弹出操作菜单（重命名/移动/标签/删除等），与原实现一致 |
| Snackbar | 全局单条、底部浮起，带可选动作按钮 |
| 列表/网格切换 | 首页与文件页的视图模式持久化于本地（Web localStorage 即可） |
| 动画 | 保持轻量：fade/slide 150–250ms；禁止引入重动画库 |
