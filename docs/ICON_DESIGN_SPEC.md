# 🎨 Snippet Studio 应用内图标重绘需求清单与设计规范

本文档为 **Snippet Studio** 应用内图标重绘（Redesign）的专业设计需求与技术规范说明书。请设计师按照本文档规定的视觉风格、网格尺寸、线宽、导出格式与交付清单进行绘制。

---

## 📐 一、 设计规范与技术注意事项

### 1. 画布网格与留白 (Grid & Padding)
- **标准画布尺寸**：`24px × 24px`。
- **安全绘制区域 (Safe Zone)**：`20px × 20px`（四周边距 Padding 各保留 `2px` 留白，防止视网膜屏及小尺寸显示时图标边缘被剪裁）。
- **视点比例一致性**：所有图标在 24px 画布中视觉体量须保持视觉平衡，圆形/方形图标视觉重感需对齐。

### 2. 风格与描边规范 (Style & Stroke Rules)
- **视觉风格**：现代极简线条风格（Outlined / Streamline Style），兼顾科技感与易读性。
- **线宽端点 (Stroke & Caps)**：
  - 推荐基础线宽：`1.8px` 或 `2.0px`。
  - 端点 (Line Caps)：圆角（Round）。
  - 连接处 (Line Join)：圆角 (Round) 或 拐角 (Miter)。
- **⚠️ 关键技术要求（必读）**：
  - **路径扩展 (Outline Stroke)**：导出前**必须将所有线条/描边扩展转换为闭合填充路径（Outline Stroke / Expand Stroke）**。
  - **图形合并 (Path Union/Flatten)**：同一图标的路径尽量做布尔运算合并（Union），避免导出重叠的冗余线段。
  - **禁止使用 CSS 样式表或遮罩 (No CSS/Masks)**：请勿包含复合蒙版（Mask）、剪裁路径（Clip-path）及外部/内联 CSS 样式，只保留纯 `<path>` 元素。

### 3. 颜色与动态染色机制 (Color & Tinting)
- **单色统一原则**：除了需要特定业务颜色的特殊图标外，**所有图标的 SVG 源码颜色统一使用纯黑 `#000000`**。
- **动态染色**：Android App 会在运行时根据明暗主题（Light/Dark Mode）及用户选择的配色主色调通过 `tint` 属性对图标进行实时涂色。因此图标源码中不能写死硬编码颜色或渐变色。

### 4. 文件导出与交付格式 (Delivery Standard)
- **导出格式**：独立 `.svg` 矢量文件。
- **命名规范**：严格按照下方清单中的“文件名”进行命名（小写字母 + 下划线分隔）。
- **坐标精简**：清理无用图层组（Group `<g>`），导出的 SVG 节点尽量结构简洁干净。

## 📦 三、 交付检查清单 (Designer Checklist)

设计交接时请确保检查以下项目：
1. [ ] 所有 52 个图标均已导出为独立的 `.svg` 文件。
2. [ ] SVG 根画板统一调整为 `24px × 24px`。
3. [ ] 描边与线条均已**转为闭合路径（Outline Stroke）**。
4. [ ] SVG 内部色彩统一为 `fill="#000000"`。
5. [ ] 文件命名无大写字母、无空格、无特殊字符，完全符合 `ic_xxx.svg` 规范。
