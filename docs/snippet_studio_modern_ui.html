🎯 现代高级感重构核心原则 (Design Tokens)

1. 表面系统分层 (Layered Surfaces)

原设计 纯白/纯黑粗暴底色，卡片缺乏厚度与进深感。
新设计 引入 3 级 Surface（Base, Surface, Elevated）结合 1px 精细弱描边（`rgba(0,0,0,0.06)` / `rgba(255,255,255,0.08)`），营造多维空间感。

2. 悬浮磨砂胶囊底栏 (Glassmorphic Dock)

原设计 传统贴底 NavigationBar，占用视口且略显笨重。
新设计 悬浮 32dp 圆角磨砂胶囊，背景高斯模糊（Backdrop Blur），内容直通底部（Edge-to-Edge）。

3. 极客等宽代码微视窗 (Monospace Preview Box)

原设计 卡片内仅展示普通文本，开发工具质感弱。
新设计 卡片内嵌 Fira Code / JetBrains Mono 风格微视窗，具备精巧的行距、语法微高亮与圆角边框。

4. 信息密度与微排版 (Typography & Micro-icons)

原设计 字重单一，标题与标签区分度不足。
新设计 Plus Jakarta Sans + Noto Sans SC 粗字重大标题，搭配胶囊状态标签（Badge）与点阵微隔断。

📱 六大核心页面优化实施方案

① 首页 (HomeScreen)

• 统计栏升级为带有状态呼吸灯与 Git 实时连接指示的现代化仪表盘。
• 常用片段卡片采用带内嵌代码微窗的卡片容器，按压微缩放（0.98x）。

② 文件与仓库 (FilesScreen)

• 文件夹采用流线平滑圆角，带有专属类型图标配色与片段数量胶囊。
• 舒适 / 紧凑 / 树状视图一键无缝切换。

③ 编辑器 (EditorScreen)

• Sora-Editor 原生全屏沉浸式代码画布，配有顶部操作轻量条。
• 底部提供常用编程符号辅助条（Symbol Bar）与变量快速填充抽屉。

④ 代码详情 (DetailScreen)

• 渐变微光 Hero Card 呈现语言类型、代码行数与文件大小。
• 4 列 Action Grid（运行、编辑、复制、分享）一触即发。

⑤ 设置与管理 (SettingsScreen)

• 分组式卡片设计（Git 同步、编辑器偏好、主题调色板、数据备份）。
• 实时主题预览盒子，切换即时生效。
